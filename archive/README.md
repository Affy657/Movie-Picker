# Archive

Ce qui a compté à un moment du projet et n'est plus vivant. Rien ici n'est construit, testé,
déployé, ni maintenu : `pnpm-workspace.yaml` ne déclare que `apps/*`, donc aucun de ces dossiers
n'est un paquet du monorepo. Les liens internes de ces documents peuvent pointer vers des fichiers
qui ont depuis bougé ou disparu.

| Dossier | Contenu |
| --- | --- |
| [`mobile/`](mobile/) | Application Expo et React Native, parité V1 avec le front, gelée en mai 2026. Il n'y a plus de `apps/mobile`. Le projet d'une vraie application mobile est porté par [`docs/roadmap.md`](../docs/roadmap.md) |
| [`docs/spec.md`](docs/spec.md) | Spécification d'origine du produit |
| [`docs/v0-mvp/`](docs/v0-mvp/) | Carte de suivi du MVP, du premier écran à la mise en ligne |
| [`docs/v1-produit/`](docs/v1-produit/) | Carte de suivi de la V1, compte utilisateur, parcours hôte, sécurité de la chaîne |
| [`docs/_ynov/`](docs/_ynov/) | Consigne d'un module de cours et la note d'architecture qui y répond |

L'état courant du produit se lit dans [`README.md`](../README.md), le
[dossier technique](https://www.movie-picker.fr/tech), [`docs/roadmap.md`](../docs/roadmap.md) et
[`CHANGELOG.md`](../CHANGELOG.md).
