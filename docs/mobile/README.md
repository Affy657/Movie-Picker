# Mobile App — Pour démarrer (IA ou humain)

Tu vas reconstruire **l'app web Movie Picker en React Native** (Expo) dans `apps/mobile/`. Tout est cadré.

## Ordre de lecture (obligatoire)

1. **[CONTEXT.md](./CONTEXT.md)** — Stack imposée, structure cible, contrat API, modèles, auth, env, règles repo.
2. **[PLAN.md](./PLAN.md)** — Étapes ordonnées et **cochables**. C'est ta to-do exhaustive.

## Règles de fonctionnement

- **Tu coches au fur et à mesure** dans `PLAN.md` (édite le fichier, passe `[ ]` → `[x]`).
- **Tu commits après chaque phase complète** avec le message conventionnel indiqué.
- **Tu ne sautes pas de phase.** Si tu bloques, écris la raison sous la case et préviens l'utilisateur.
- **Tu lis les fichiers cités dans CONTEXT.md** (AGENTS.md, `.cursor/rules/*`) avant de commencer.
- **Tu ne push pas** sans avoir passé `pnpm run verify:local` à la racine.

## Premier prompt suggéré pour relancer l'IA

> "Suis `docs/mobile/PLAN.md`. Commence par la phase 0, coche les cases au fur et à mesure dans le fichier, et ne passe pas à la phase suivante avant que toutes les cases de la phase courante soient cochées."
