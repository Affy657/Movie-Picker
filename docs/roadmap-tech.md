# Movie Picker – Roadmap tech

La roadmap technique est fusionnée dans [roadmap-product.md](roadmap-product.md).

Chaque version y porte d'abord ses features, puis une section **Tech** pour le travail transverse : infra et déploiement, CI/CD et qualité, sécurité, observabilité, accessibilité. Les chantiers non planifiés sur une version, dont les huit lots Terraform, sont dans **Backlog tech**, à la fin du même fichier.
